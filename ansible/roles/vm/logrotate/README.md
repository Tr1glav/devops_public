# vm/logrotate

Базовые logrotate-конфиги для системных логов.

## Использование

```yaml
- hosts: all
  become: true
  roles:
    - vm/logrotate
```

## Переменные

| Переменная | По умолчанию | Описание |
|---|---|---|
| `rotate_weeks` | `4` | Недель хранения |
| `max_log_size` | `100M` | Максимальный размер до ротации |
| `min_log_size` | `1K` | Минимальный размер для ротации |
| `extra_log_configs` | `[]` | Дополнительные конфиги (список) |

## Примечания

- Хендлеры: `Restart rsyslog`, `Force logrotate` (принудительная ротация).
